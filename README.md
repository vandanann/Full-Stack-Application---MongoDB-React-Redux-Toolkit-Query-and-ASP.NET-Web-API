# Full-Stack-Application-MongoDB-React-Redux-Toolkit-Query-and-ASP.NET-Core-Web-API

1. Technology stack
Frontend
React + TypeScript
- React
- Redux Toolkit
- RTK Query
- React Router
- Bootstrap


Backend
ASP.NET Core Web API
- .NET 10
- REST API
- DTOs
- Services
- Validation


Database
MongoDB
- MongoDB Atlas or local
- MongoDB.Driver
- BSON documents



2. Application features
Core functionality
- Create a lead
- View all leads in a table
- Edit lead information
- Update lead status
- Delete lead with confirmation
- Search by name
- Filter by status
- Validate inputs in React and API
Bonus features
- Dashboard cards for status totals
- Pagination
- Sorting
- Signup and login with JWT
- User-specific leads
- API tests
- Deployment





The React frontend will communicate with ASP.NET Core through HTTP REST endpoints. RTK Query will manage API calls, caching, loading states, and cache invalidation.
